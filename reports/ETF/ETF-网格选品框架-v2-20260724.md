## 一、新选品框架：四层过滤

### 数学关系

```
网格年化收益 ≈ 底层资产年化 × 0.6 + 波动交易超额

其中:
  底层资产年化 × 0.6: 网格只持有 60-70% 仓位暴露（其余是现金）
  波动交易超额: 网格交易本身的 α，通常 3-7%

当底层资产年化 = +20% → 网格 ≈ +15%
当底层资产年化 =   0% → 网格 ≈ +3%
当底层资产年化 = -20% → 网格 ≈ -8%
```

**波动交易的超额覆盖不了底层资产的大幅下跌。** 这是数学约束，不是参数能改变的。

### 四层过滤

```
第一层: 长期方向 ← 必须通过
  宽基指数: 默认通过（代表经济体长期增长）
  行业 ETF: 仅选有结构性增长的行业
  排除: 长期下行趋势的行业（无论多便宜）

第二层: 均值回归特性 ← 决定网格能不能赚钱
  宽基 > 行业（宽基代表整体经济，均值回归确定性更高）
  周期行业 > 结构性衰退行业
  检验: 过去 3 年从低点反弹的幅度和速度

第三层: 估值门槛 ← 排除依据，不是排名依据
  PE分位 > 80%: 排除（太贵，下跌风险大）
  PE分位 20-80% 且通过前两层: ✅
  PE分位 < 20% 但行业结构性衰退: 排除（价值陷阱）

第四层: 趋势择时 ← 决定何时开、开多大
  BB < 10% 且 趋势 ≥ -1: 全开双向网格
  BB 10-20% 或 趋势 -3~-2: 仅底仓+卖出
  BB > 20% 或 趋势 ≤ -4: 不开
```

### v1 vs v2 对比

| | v1 框架 | v2 框架 |
|------|------|------|
| 第一标准 | 估值低（PE分位排序） | **长期方向**（底层资产是否向上） |
| 波动权重 | 35%（最高） | 仅用于参数设置，不用于选品 |
| 估值角色 | 排名依据 | 排除依据（过贵排除） |
| 行业偏好 | 周期行业加分 | 先看方向，再看周期 |
| 致命漏洞 | 选出了"便宜但持续跌"的品种 | 四层过滤阻止价值陷阱 |

## 七、核心原则总结

1. **方向第一，估值第二。** 底层资产长期向上是网格赚钱的前提。便宜的垃圾不会因为网格交易变成金子。
