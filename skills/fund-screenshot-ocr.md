# 基金/股票持仓截图 → Excel 解析

读取**天天基金**、**东方财富**或**招商银行** App 的持仓/成交截图，提取持仓信息和成交记录，合并去重后生成 Excel 文件。

支持四种截图类型：
- **天天基金「我的持仓」**：场外基金持仓列表（金额/收益率视角）
- **东方财富「交易-持仓」**：场内 ETF/股票持仓（股数/成本价视角）
- **东方财富「交易-成交记录」**：当日/历史委托成交明细（用于交叉校验）
- **招商银行「基金持仓」**：银行端基金持仓列表或详情页（含份额、净值、成本价、银行卡尾号）

## 输入

- **一到多张**截图（PNG/JPG），可以是以下任意组合：
  - 天天基金 App 的"我的持仓"页面截图（支持多张滚动截图）
  - 东方财富 App 的"交易"→"持仓"页面截图
  - 东方财富 App 的"交易"→"当日成交"或"历史成交"页面截图
  - 招商银行 App 的"财富"→"基金"→持仓列表或单只基金详情页截图
- 输出 Excel 文件名（可选，默认 `reports/ETF/持仓数据-{YYYYMMDD}.xlsx`）

### 图片类型自动识别（优先级决策树）

**按以下优先级判断，命中即停止。高优先级信号 > 低优先级信号。**

#### 第一优先级：铁证信号（100% 确定）

| 铁证信号 | 结论 | 理由 |
|---------|------|------|
| 出现「银行卡尾号」 | **招商银行 详情页** | 只有银行 App 显示卡尾号 |
| 出现「在途资金」 | **招商银行**（列表或详情） | 只有银行 App 有此字段 |
| 出现「银证转账」 | **东方财富 持仓页面** | 券商独有功能 |
| 出现「证券买入」/「证券卖出」 | **东方财富 成交记录** | 券商交易方向术语 |
| 出现「当日委托」+ 时间+价格+数量 | **东方财富 成交记录** | 交易流水独有格式 |

#### 第二优先级：平台专属布局（95% 确定）

| 布局特征 | 结论 |
|---------|------|
| 顶部大字「总资产」+ 「证券市值」+ 「可用/可取」三行 | 东方财富 持仓页面 |
| 每行一个基金，字段为「代码 + 名称 + 资产 + 持仓收益/率 + 昨日收益」 | 天天基金 持仓列表 |
| 每行一个基金，字段为「代码 + 名称 + 金额(元) + 持仓收益 + 收益率」 | 招商银行 持仓列表 |
| 单只基金全屏，显示「最新净值」「持仓成本价」「可用份额」三个字段 | 招商银行 详情页 |
| 列表中有「场内基金/市值」「批量加仓」「批量卖出」按钮 | 东方财富 持仓页面 |

#### 第三优先级：综合打分（多信号加权）

当铁证信号缺失、布局模糊时，按以下规则打分，得分最高者胜出：

**天天基金得分项（每项 +1）：**
- 出现「资产」而非「金额(元)」作为价值标签
- 出现「累计收益」（天天基金特有字段名）
- 多只基金以列表形式纵向排列，各基金之间有分隔
- 出现「基金诊断」或「AI基金诊断」
- 底部有「自选/行情/理财/交易」等天天基金导航栏

**东方财富得分项（每项 +1）：**
- 出现「持仓/可用」「现价/成本」这类复合列头（券商特有格式）
- 出现「当日盈亏」（券商用词，vs 天天基金用「昨日收益」）
- 顶部出现「总资产」大字 + 数值
- 底部有「自选/行情/理财/交易首页」导航栏

**招商银行得分项（每项 +1）：**
- 出现「金额(元)」而非「资产」作为价值标签
- 出现「持有XX天」
- 出现「产品详情」+「晒收益」按钮
- 出现「日涨幅」字段
- 页面顶部有返回箭头 `<` + 基金公司名 + `©)` 或类似符号

#### ⚠️ 禁止行为

- **禁止跨平台推断基金代码**：招商银行截图缺失代码时，不能从天天基金数据中猜测。应通过搜索引擎查询基金名称+代码来确认。
- **禁止凭基金名称相似度判断**：OCR 截断的标题（如"易方达沪深"）不能推断完整代码，必须查证。

## 天天基金持仓截图字段说明

天天基金"我的持仓"列表视图通常只显示以下字段（⚠️ 不显示份额和净值）：

| 常见列 | 说明 | 是否必有 |
|--------|------|:------:|
| 基金代码 | 6位数字，如 013308 | ✅ 必有 |
| 基金名称 | 如"易方达恒生科技ETF联接(QDII)A" | ✅ 必有 |
| 持仓市值/资产 | 当前持仓的市值金额 | ✅ 必有 |
| 累计收益 | 自买入以来的累计盈亏金额 | ✅ 必有 |
| 持仓收益率 | 累计收益/投入本金，百分比 | ✅ 必有 |
| 昨日收益 | 前一交易日的盈亏金额 | ✅ 必有 |
| 持有份额 | 当前持有多少份 | ❌ 列表视图通常不显示 |
| 最新净值 | 单位净值 | ❌ 列表视图通常不显示 |

- "持仓/可用"可能被 OCR 识别为两列数值，需要按格式 `{持仓}/{可用}` 解析
- "现价/成本"可能被 OCR 识别为两列数值，需要按格式 `{现价}/{成本}` 解析

## 东方财富成交记录截图字段说明

东方财富"当日成交"或"历史成交"页面，每条记录包含：

| 字段 | 说明 | OCR 后示例 |
|------|------|-----------|
| 日期 | 交易日期 | 2026-07-15 |
| 时间 | 交易时间（精确到秒） | 09:54:54 |
| 名称 | 证券简称 | 恒指科技 |
| 代码 | 6位数字 | 513180 |
| 价格 | 成交价格 | 0.597 |
| 数量 | 成交股数 | 300 |
| 方向 | 证券买入 / 证券卖出 | 证券卖出 |
| 金额 | 成交金额（不含手续费） | 179.10 |

**成交记录的核心价值——交叉校验持仓成本：**

用成交记录可以反向推算当前持仓的成本：
```
加权成本 = Σ(买入金额) / Σ(买入股数)
当前持仓 = Σ(买入股数) - Σ(卖出股数)
```

将反推结果与持仓页面 OCR 提取的成本对比，偏差 > 2% 标记 ⚠️。

## 执行流程

### 第一步：逐一读取图片并提取文字

**对每张图片依次执行：**

1. 使用 OCR 提取图片中的所有文字（`pytesseract`，中英文混合识别）
2. 图片预处理：放大 2 倍 + 增强对比度 + 锐化，提高识别准确率
3. 输出每张图片的完整 OCR 结果（原始文本），标注图片编号

**OCR 脚本模板：**
```python
import pytesseract
from PIL import Image, ImageFilter, ImageEnhance

def ocr_image(img_path):
    img = Image.open(img_path)
    w, h = img.size
    # 放大2倍提高精度
    img = img.resize((w * 2, h * 2), Image.LANCZOS)
    # 增强对比度 + 锐化
    img = ImageEnhance.Contrast(img).enhance(2.0)
    img = img.filter(ImageFilter.SHARPEN)
    text = pytesseract.image_to_string(img, lang='chi_sim+eng', config='--psm 3')
    return text
```

### 第二步：识别图片类型

**按优先级决策树判断每张图片的平台和页面类型，不得跳过铁证信号。**

```
// 铁证优先
if OCR包含 "银行卡尾号" or "在途资金":
    → 招商银行
    if 单只基金全屏 + 有"可用份额""最新净值""持仓成本价":
        → 招商银行 详情页
    else:
        → 招商银行 持仓列表

if OCR包含 "银证转账":
    → 东方财富 持仓页面

if OCR包含 "证券买入" or "证券卖出" or "当日委托":
    → 东方财富 成交记录

// 布局判断
if OCR包含 "总资产" + "证券市值":
    → 东方财富 持仓页面

if OCR包含 "持仓/可用" + "现价/成本" (复合列头):
    → 东方财富 持仓页面

if OCR包含 "最新净值" + "持仓成本价" + "可用份额" (三字段同时出现):
    → 招商银行 详情页

if OCR包含 "累计收益" (注意不是"持仓收益"):
    → 天天基金 持仓列表

// 兜底打分
得分 = max(天天基金得分, 东方财富得分, 招商银行得分)
→ 得分最高者
```

### 第三步：按类型提取结构化数据

#### A. 天天基金持仓 → 提取基金记录

1. **逐行解析**：识别出每只基金的完整记录
2. **提取字段**：基金代码（6位数字）、基金名称、持仓市值、累计收益、持仓收益率、昨日收益
3. **标注来源**：`source: tiantianfund`
4. **标注缺失**：某字段 OCR 无法识别时，标注 `N/A`

#### B. 东方财富持仓 → 提取账户概览 + 持仓明细

**账户概览**（从顶部区域提取）：
- 总资产、证券市值、可用资金、可取资金、当日盈亏

**持仓明细**（从列表区域提取）：
1. **名称-代码关联**：OCR 可能将名称和代码分离到不同行，通过数字特征（6 位或 3-6 位代码）在相邻行间关联
2. **多值字段拆分**：
   - `持仓/可用` 列 → 解析为 `{shares}/{available}` 两组数值
   - `现价/成本` 列 → 解析为 `{price}/{cost}` 两组数值
3. **提取字段**：名称、代码、持仓股数、可用股数、现价、成本价、浮动盈亏金额、盈亏率
4. **标注来源**：`source: eastmoney_position`
5. **验算**：`(现价 - 成本价) × 持仓股数` 应约等于浮动盈亏，偏差 > 3% 标记 ⚠️

#### C. 东方财富成交记录 → 提取交易流水

1. **逐条解析**：每条记录包含日期、时间、名称、代码、价格、数量、方向、金额
2. **日期关联**：OCR 可能将日期行（如"2026-07-15"）与后续多笔交易分离，需要向下关联
3. **方向判断**：`买入` → buy，`卖出` → sell
4. **记录合并**：同一日期同一代码的所有交易按顺序列出
5. **标注来源**：`source: eastmoney_transaction`

#### D. 招商银行基金持仓 → 提取基金详情

**持仓列表**：
- 提取字段：基金代码、基金名称、持仓金额、持仓收益、收益率、昨日收益
- 标注来源：`source: cmb_list`

**单只基金详情页**：
1. **提取字段**：基金名称（从页面标题提取，OCR 可能截断）、金额、持有天数、昨日收益、持仓收益、收益率、可用份额、最新净值（含日期）、成本价、银行卡尾号、在途资金、日涨幅
2. **基金代码识别**：招商银行详情页标题通常只显示基金简称且可能被 OCR 截断。如果代码在标题中不可见，**不得跨平台推断代码**。应按以下步骤确认：
   - a. 从标题 OCR 提取基金名称关键信息（如"易方达沪深""南方纳斯达""摩根标普500"）
   - b. 用搜索引擎查询 `"{基金名称关键词}" "基金代码"` 找到候选代码
   - c. 交叉验证：用候选代码查到的净值、基金类型与截图 OCR 的净值和类型是否一致
   - d. 确认后标注代码，并在备注中注明"通过搜索引擎查证"
3. **卡尾号分组**：银行卡尾号相同 = 同一银行账户，不同尾号 = 不同资金账户，Excel 中按卡尾号分组
4. **标注来源**：`source: cmb_detail, card: XXXX`
5. **验算**：`金额 ≈ 可用份额 × 最新净值`，偏差 > 1% 标记 ⚠️

### 第四步：同平台去重与合并

#### 天天基金多图合并

1. **按基金代码去重**：代码相同的记录视为同一只基金
2. **重叠数据校验**：滚动截图的相邻图之间至少有一行重叠，对比两次 OCR 结果，取可读性更好的值，标记"双次校验 ✅"
3. **补齐缺失**：某字段在 A 图中模糊、B 图中清晰，用 B 图值补齐

#### 东方财富持仓与成交记录交叉校验（关键步骤）

用成交记录反推持仓，验证 OCR 准确性：

```python
# 从成交记录反推
total_buy_shares = sum(t.quantity for t in transactions if t.direction == 'buy')
total_sell_shares = sum(t.quantity for t in transactions if t.direction == 'sell')
calculated_shares = total_buy_shares - total_sell_shares

total_buy_amount = sum(t.amount for t in transactions if t.direction == 'buy')
# 考虑卖出对成本的调整（先进先出简化处理）
calculated_cost = (total_buy_amount - total_sell_shares * sold_cost_estimate) / calculated_shares
```

对比 OCR 提取的持仓数量和成本，偏差 > 3% 标记 ⚠️ 并提示用户核实。

### 第五步：跨平台交叉验证

天天基金（场外基金）、东方财富（场内 ETF/股票）、招商银行（银行端基金）**本质上是不同的持仓体系，不必强行合并**。但需注意：

- **天天基金 vs 招商银行**：同一基金可能在两个平台分别持有（不同账户），金额不一致是正常的，分别列出，标注所属平台
- **招商银行内部**：按「银行卡尾号」区分不同资金账户，同一卡尾号的基金归入同一账户
- **天天基金 vs 东方财富**：同一标的（如 513180）可能既有场外联接基金又有场内 ETF，代码不同，不要混淆
- 天天基金数据以"金额+收益率"为主，东方财富以"股数+成本价"为主，招商银行详情页**同时有份额和成本价**（与天天基金互补）

### 第六步：数据校验

- **金额合理性**：持仓市值、累计收益、成交金额在合理范围内，异常值标记 ⚠️
- **收益率验算（天天基金/招商银行）**：`收益率 ≈ 累计收益 / (持仓金额 - 累计收益)`，偏差 > 2% 标记 ⚠️，偏差 > 10% 标注为 OCR 错误并用验算值替代
- **净值验算（招商银行详情页）**：`金额 ≈ 可用份额 × 最新净值`，偏差 > 1% 标记 ⚠️
- **收益率 OCR 易错提醒**：OCR 经常丢掉百分号前的首位数字（如 17.35% → 7.35%，11.56% → 1.56%），**所有百分比必须验算**，不得直接信任 OCR 结果
- **盈亏验算（东方财富）**：`(现价 - 成本价) × 持仓股数` 应约等于浮动盈亏，偏差 > 3% 标记 ⚠️
- **成交记录反推验算（东方财富）**：成交记录反推的持仓数量应与 OCR 提取一致，偏差 > 3% 标记 ⚠️
- 所有金额保留两位小数，份额保留整数（ETF）/ 两位小数（场外基金）

## 注意事项

- **多图优先提供**：如果持仓超过 5 只，大概率需要滚动截图，尽量一次提供所有截图，避免分次识别导致合并遗漏
- **图片顺序**：多张截图时按从上到下的滚动顺序标注（图1=最顶部，图N=最底部）
- **重叠校验**：相邻两张图之间至少有一行重叠，用于验证 OCR 准确性
- **图片清晰度**：模糊、反光、字体过小会降低 OCR 准确率，关键字段可能需人工校对
- **数据时点**：提取的净值和盈亏是截图时刻的快照
- **隐私保护**：所有数据仅保存在本地 Excel，不通过网络传输
- **缺失字段**：天天基金列表视图不显示份额和净值，这些字段在 Excel 中标记 N/A，如需完整数据需进入单只基金详情页截图
- **OCR 局限**：基金代码、数字金额是 OCR 易错点，务必展示给用户确认后再生成 Excel
- **东方财富 OCR 特殊难点**：
  - 代码可能和名称分行显示，需通过相邻行间的数字特征关联
  - `持仓/可用` 和 `现价/成本` 是复合列，需拆分为两个独立数值
  - 东方财富截图可能包含广告/弹窗元素，OCR 后需过滤无关文本
  - 成交记录中日期可能只显示一次（多笔同日期交易共用一个日期头），向下关联时注意边界
- **ETF vs 基金区分**：东方财富显示的是场内 ETF/股票（按股数交易），天天基金显示的是场外基金（按金额申购），二者是不同的资产类型，不要混淆代码相同的 ETF 和其联接基金
- **成交记录不全**：东方财富"当日成交"只显示当日，"历史成交"默认近一周，如需完整成交记录需调整查询区间多次截图

## 常见错误与纠正（必读）

### 错误 1：把招商银行详情页误判为天天基金

**症状**：OCR 标题被截断（如只显示"易方达沪深 ©) 53)"），凭基金名称猜测代码。

**纠正**：
- 只要 OCR 中出现「银行卡尾号」或「在途资金」，100% 是招商银行
- 天天基金**从不**显示银行卡尾号和在途资金
- 招商银行详情页字段顺序是：「金额(元)」→「昨日收益」「持仓收益」「持仓收益率」→「在途资金」「可用份额」→「最新净值」「持仓成本价」→「银行卡尾号」

### 错误 2：跨平台推断基金代码

**症状**：招商银行截图 OCR 看不清代码 → 去天天基金列表里找名称相似度高的基金 → 直接复用代码

**纠正**：
- 天天基金和招商银行是**独立账户**，持有的基金集合可能完全不同
- 同一基金（如易方达沪深300增强）在 A 平台持有 C 份额（010737），在 B 平台持有 Y 份额（022914），代码不同
- 招商银行代码缺失 → **搜索引擎查证**，不跨平台猜测

### 错误 3：OCR 多值字段解析错误

**症状**：东方财富「持仓/可用」「现价/成本」被当成一个数值

**纠正**：
- 东方财富的「9200\n9200」是「持仓\n可用」→ 拆成 9200 和 9200
- 东方财富的「0.613\n0.573」是「现价\n成本」→ 拆成 0.613 和 0.573
- 天天基金的「+33.24\n+0.51%」是「累计收益\n收益率」→ 拆成 +33.24 和 +0.51%

### 错误 4：混淆天天基金和招商银行的字段名

| 天天基金 | 招商银行 | 说明 |
|---------|---------|------|
| 「资产」 | 「金额(元)」 | 标签名不同 |
| 「累计收益」 | 「持仓收益」 | 字段名不同 |
| 「持仓收益率」 | 「持仓收益率」 | 相同 |
| 「昨日收益」 | 「昨日收益」 | 相同 |
| 无 | 「在途资金」 | 招商银行独有 |
| 无 | 「银行卡尾号」 | 招商银行独有 |
| 无 | 「持有XX天」 | 招商银行独有 |
| 无 | 「可用份额」「最新净值」「持仓成本价」 | 招商银行详情页独有 |
