## 一、中国四大经济周期的嵌套与叠加

### 1.1 四层周期的经典框架

```
1个康波周期(50-60年) ≈ 3个库兹涅茨周期 ≈ 6个朱格拉周期
1个朱格拉周期(8-10年) ≈ 3个基钦周期
1个库兹涅茨周期(15-25年) ≈ 2-3个朱格拉周期
```

### 1.2 四周期在 2025 年的位置（三周期共振）

| 周期 | 时长 | 当前阶段 | 方向 | 核心信号 |
|------|------|---------|------|---------|
| **基钦周期（库存）** | 3-4年 | 主动去库存尾→被动去库存过渡 | 筑底 | PMI连续<50，PPI降幅收窄 |
| **朱格拉周期（产能/设备）** | 8-10年 | 新一轮扩张初期 | **上行** | 设备投资+14%，高技术+34% |
| **库兹涅茨周期（房地产）** | 15-25年 | 深度调整后期 | 下行 | 投资-14%，新开工-19% |
| **康波周期（长波）** | 50-60年 | 五波萧条末→六波复苏初 | 转换 | AI+新能源+生命科学驱动 |

### 1.3 周期叠加的核心矛盾

**2025年是四周期"三上一下"的关键年份**：

- **上行动力**：朱格拉（设备投资扩张）→ 中期支撑
- **上行动力**：康波（新技术革命）→ 长期支撑
- **上行动力**：基钦（库存筑底回升）→ 短期支撑
- **下行动力**：库兹涅茨（房地产）→ 核心拖累

> 周金涛的框架：一个人一生的财富机会主要由康波周期决定。当前处于第五轮康波萧条期末端，正在向第六轮康波的复苏初期过渡。

### 1.4 中国经济的历史演变

**五轮内需刺激周期**（联储证券）：

| 轮次 | 时间 | 类型 | 核心驱动 |
|------|------|------|---------|
| 第一轮 | 1998-2002 | 制度破局型 | 房改+入世 |
| 第二轮 | 2008-2011 | 总量强拉动型 | 四万亿 |
| 第三轮 | 2014-2018 | 消费升级型 | 房地产财富效应 |
| 第四轮 | 2020-2022 | 纾困托底型 | 疫情对冲 |
| **第五轮** | **2024至今** | **内需刺激型** | 宽财政+松货币+产业升级 |

**K型经济的本质**：出口高增但消费低迷。传统的"出口→制造业扩产→就业收入提升→消费回暖"传导链条正在失效。

三个失效原因：
1. **以价换量**：工业企业利润率从 6.09% 降至 5.31%
2. **自动化替代就业**：工业机器人密度突破 400 台/万人，全球新增装机 52%
3. **结汇率走低**：大量出口外汇留存海外

### 1.5 新旧动能切换的历史性时刻

中信建投测算：
- 新动能（TMT+汽车）GDP占比：**21.5%**
- 旧动能（房地产+建筑业）GDP占比：**24.5%**
- **预计 2029 年新动能超越旧动能**（若科技非线性发展则更早）

## 二、中国股市的历史使命与功能定位

### 2.1 从"晴雨表"到"发动机"

股市的核心定位已发生根本改变：

| 旧定位 | 新定位 |
|--------|--------|
| 经济晴雨表（被动反映） | 经济发动机（主动引领） |
| 融资工具 | 投融资协调平台 |
| 散户投机场所 | 居民财富管理核心渠道 |
| 国有企业解困工具 | 科技创新策源地 |

### 2.2 三大核心功能

**1. 科技创新的策源地**
- 科创板允许未盈利企业、特殊股权结构企业上市
- 股权市场是唯一能为"未来价值"定价的金融工具
- "研发—融资—产业化—再研发"的创新闭环

**2. 产业升级的导航仪**
- 市场化估值引导资金流向先进制造、新能源、AI、生物医药
- 推动经济向高端化、智能化、绿色化转型

**3. 居民财富的发动机**
- 投资者超 2.37 亿户
- 目标：扩大中等收入群体、夯实内需增长根基

### 2.3 "十五五"改革核心方向

1. **投融资功能协调**：从"重融资轻回报"转向两端平衡
2. **央行工具介入**：央行创设资本市场货币政策工具，提供流动性兜底
3. **全面注册制**：企业价值判断交还市场
4. **常态化退市**：打破刚性兑付预期
5. **长期资金入市**：养老金、保险、社保提高权益投资比例

### 2.4 当前市值与融资现状

- A股累计股权融资超 20 万亿元
- 自 1993 年以来 A 股几何平均回报率仅约 3.3%（远低于发达市场）
- 正从"融资市"向"投资市"转型

## 三、行业生命周期与周期定位

```
下行期 → 出清初期 → 出清中期 → 出清末期 → 回升期 → 扩张期 → 筑顶期
  └────── 左侧（反转策略）──────┘    └──── 右侧（景气策略）────┘
```

## 四、2024-2025 A股行业轮动完整复盘

### 4.1 轮动脉络

```
金融防御 → 政策反转 → 科技先行 → 周期接棒 → 消费蓄势
```

| 时段 | 主导风格 | 核心板块 |
|------|---------|---------|
| 2024.1-8 | 大盘价值防御 | 银行+42%、公用事业、出口链 |
| 2024.9 | 政策反转全行业暴涨 | 金融科技+43%、房地产+36%、非银+36% |
| 2024.10-12 | 震荡整固 | 商贸零售、红利、AI发酵 |
| 2025.1-3 | AI主线爆发 | 算力、应用端、通信 |
| 2025.5-7 | 周期涨价主升 | 贵金属→铜铝→化工能源、医药走强 |
| 2025.7起 | 震荡后期切换 | 半导体、AI科创板酝酿接力 |
| 2025末-2026 | 风格切换窗口 | 化工能源尾声→消费等待 |

### 4.2 行业轮动的经典路径

```
贵金属(金融属性先行)→铜铝(工业金属)→化工/能源(实物资产)→消费(PPI→CPI传导)
```

**当前阶段**：化工能源正处行情核心，消费仍在"黎明前"，有色估值已修复到历史较高水平。

### 4.3 本轮的核心新增变量

**"反内卷"政策**：与 2015 年供给侧改革本质不同 — 更强调市场化、行业自律、标准引领。效果更温和但更长效。核心影响：
- 提升生产要素价格，推升内需
- 改善传统行业 ROE 和利润率
- 预计 PPI 于 2025 年四季度出现显著拐点

**AI 作为需求侧第二增长曲线**：新能源+AI 已占全球铜总需求 20%+ 且持续高速增长。

### 4.4 牛市三阶段风格切换模型

| 阶段 | 特征 | 占优风格 |
|------|------|---------|
| **快涨期** | 超跌修复 | 前轮牛市强势行业领跑 |
| **震荡期** | 风格切换枢纽 | 低价股、题材→向业绩集中 |
| **主升浪** | 盈利驱动 | 消费或成长成为主线 |

## 五、对投资决策的核心启示

### 5.1 周期定位决定策略

1. **库存周期**（基钦）决定**短期仓位** — 补库存时进攻，去库存时防御
2. **产能周期**（朱格拉）决定**中期方向** — 设备投资扩张时关注制造业
3. **地产周期**（库兹涅茨）决定**风险偏好** — 地产下行时防御为主
4. **技术周期**（康波）决定**长期赛道** — AI+新能源+生命科学

### 5.2 当前（2026年中）最核心的判断

1. **房地产仍未见底** — 库兹涅茨周期下行是最大拖累，预计调整至 2026-2027 年
2. **设备投资高增长** — 朱格拉周期扩张是最大支撑，制造业升级是中期主线
3. **AI 仍是第一景气赛道** — 光模块/芯片处于繁荣期
4. **反内卷政策是最大的新增变量** — 传统行业供给出清后 ROE 修复
5. **消费黎明前** — 白酒 PE 18.6 倍处于十年新低，等待 PPI→CPI 传导
6. **股市从"融资市"向"投资市"转型** — 投融资协调、长钱入市、回购分红增加

### 5.3 对 ai-invest 的启示

1. **行业分析需要周期定位** — 不同周期位置，估值逻辑完全不同（出清期看 PB，扩张期看 PE）
2. **反内卷/供给出清是判断传统行业拐点的关键变量** — 不再是需求侧单维度
3. **K 型分化长期存在** — 新经济和旧经济的分化只会加剧，选赛道比选个股更重要
4. **投融资协调的政策方向意味着分红/回购将成为选股核心因子**
