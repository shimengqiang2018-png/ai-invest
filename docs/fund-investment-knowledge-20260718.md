## 一、基金评价体系

### 1.1 500+指标多维标签矩阵（2024行业标准）

头部券商已将基金评价体系升级为覆盖七大维度的标签矩阵：

| 标签大类 | 核心指标 |
|---------|---------|
| **基金综合能力** | 收益类、风险调整收益类综合评分 |
| **多维投资能力** | 选股能力、择时能力、行业配置能力 |
| **风格标签** | 市值风格（大/中/小盘）+ 价值-成长风格五分类 |
| **行业配置标签** | 配置偏好、交易特征、九宫格均衡度 |
| **组合管理特征** | 集中度、换手率、热门度、拥挤度、勤奋度 |
| **基金经理特征** | 履历、业绩记录、投资方法论、定性标签 |
| **基金公司运营** | 平台规模、投研团队、机构与员工占比 |

### 1.2 风格划分体系

**市值风格三分类**：大盘 → 中盘 → 小盘
**价值-成长风格五分类**：深度价值 → 价值 → 价值成长(GARP) → 均衡成长 → 成长
**行业配置九宫格**：基于行业配置均衡度（分散/集中）× 变动度（稳定/灵活）

### 1.3 常用业绩评价指标

| 指标类别 | 具体指标 | 含义 |
|---------|---------|------|
| **风险调整收益** | 夏普比率、信息比率、索提诺比率、卡玛比率 | 承担单位风险的回报 |
| **风险指标** | 标准差、贝塔、最大回撤、波动率 | 波动和损失程度 |
| **收益指标** | 净值增长率、年化收益率 | 绝对回报 |
| **持有体验** | 创新高频率、回撤修复周期 | 持有者的实际感受 |
| **规模结构** | 基金规模（负向预测）、机构占比（正向预测） | 规模和资金结构信号 |

## 二、选基方法论（2024-2025前沿）

### 2.1 七维多因子框架

2025年最完整的选基因子体系包含 200+ 指标，覆盖七个维度：

| 因子类别 | 有效性 | 核心发现 |
|---------|--------|---------|
| **收益类因子** | 中 | 中长期信息比率较优，短期不稳定 |
| **风险类因子** | 低 | 整体无预测效果，短期Beta可捕捉趋势 |
| **Alpha类因子** | **高** | 选股能力是区分基金好坏的最核心因子 |
| **风格类因子** | 中 | 随市场阶段性有效，需动态跟踪 |
| **拥挤度因子** | **高（负向）** | 板块和行业拥挤度长期稳定负向预测 |
| **组合管理因子** | 低 | 更多描述操作特征，非预测变量 |
| **平台类因子** | 中 | 基金规模负向，机构占比正向 |

### 2.2 拥挤度因子：2025最重要的新发现

这是近两年选基方法论最大的突破：
- 拥挤度 = 有多少基金持有了同样的股票/板块
- **拥挤度越高，未来收益越低** — 稳健的负向预测能力
- 当太多基金经理挤在同一个赛道时，即使赛道本身不错，超额收益也已经消失
- 基于拥挤度+Alpha的增强框架，年化超额可达 5.87%

### 2.3 非线性选基（2025新方向）

传统线性因子测试的短版被发现后，聚类分析成为新工具：
- 分层聚类可高效归纳优质基金的**整体画像**
- 2024年下半年的画像：「高换手 + 高仓位 + 高独立选股能力」
- 基于聚类构建的组合年化超额 4.70%

### 2.4 业绩回溯期选择

**关键洞察**：不是回溯期越长越好
- **中等期限（半年到两年）**显著优于短期和长期
- 风险类指标以短期回溯更优
- 近两年风险调整收益和选股能力指标出现衰减，需动态跟踪

## 三、业绩归因体系

### 3.1 Brinson归因模型

将基金超额收益拆解为三个来源：

```
超额收益 = 配置收益（择时能力）+ 选择收益（选股能力）+ 交互收益
```

| 收益来源 | 含义 | 实证发现 |
|---------|------|---------|
| **配置收益** | 超配/低配行业带来的收益 | 公募基金整体**不具备择时能力** |
| **选择收益** | 行业内选好股票带来的收益 | **最核心的超额收益来源**（季均 2.14%） |
| **交互收益** | 两者共同作用 | 占比小 |

**核心结论**：选股能力是绩优基金 vs 劣后基金的唯一显著区别。择时能力在统计上不存在。

### 3.2 多模型验证体系

- **Fama-French 三因子**：评估 Alpha（选股能力）
- **T-M 模型**：通过二次项评估择时能力
- **H-M / C-L 模型**：择时能力的另一种测量

Brinson模型的行业内选股能力与Fama-French的Alpha**显著正相关**，两种方法互相验证。

### 3.3 完整评估流程

1. **净值分析**：Alpha、夏普比率、信息比率、最大回撤
2. **持仓穿透**（Brinson）：资产配置贡献、行业配置贡献、选股贡献
3. **风险暴露**（Barra/Fama-French）：风格因子暴露分析
4. **定性判断**：换手率、持仓集中度、投资方法论一致性

## 四、ETF投资实战体系

### 4.1 策略分类

| 策略类型 | 代表方法 | 适用场景 |
|---------|---------|---------|
| **配置策略** | 股债恒定比例、风险平价、美林时钟、全天候 | 长期资金，稳健配置 |
| **交易策略** | 定投、网格交易、套利 | 择时能力不强的小资金 |
| **核心-卫星** | 宽基做底仓 + 行业主题做进攻 | 最受推崇的策略框架 |

### 4.2 网格交易

**本质**：在预设价格区间内，设定多个"格子"，每到一格自动买卖。

**适用条件**：
- 高弹性标的（创业板 ETF 等 20% 涨跌幅品种）
- 震荡市（单边上涨/下跌都会失效）
- 有券商自带网格功能自动执行

**参数设置**：
- 顶和底的确定（考验趋势判断能力）
- 每格买卖份额
- 网格间距（高波动→宽步长 3-5%，低波动→窄步长 1-2%）

### 4.3 定投策略

**核心逻辑**：固定时间固定金额，低位多买、高位少买，平均成本。

**关键纪律**：
- 止盈目标：持仓收益率达到预期（如 30%）→ 部分或全部止盈
- 止盈后继续定投，形成滚雪球循环
- 定投时间足够长时，具体时点和频率不重要

**局限**：能平均成本但**不能规避市场风险**。单边下跌市中定投也会亏损。

### 4.4 选 ETF 的四步法

1. **看规模**：规模太小（< 2亿）流动性差，有清盘风险
2. **看流动性**：日均成交额
3. **看跟踪误差**：跟踪误差越小越好（< 2% 年化）
4. **看费率**：管理费+托管费，越低越好（宽基 ETF 可低至 0.2%/年）

额外关注：折溢价率（大幅溢价时买入多付钱，大幅折价时卖出少拿钱）

## 五、组合构建方法

### 5.1 核心-卫星策略（最推荐）

```
核心资产 (60-80%)   宽基指数 ETF（沪深300、A500、创业板）
卫星资产 (20-40%)   行业/主题 ETF（科技、医药、消费等）
```

**设计原则**：
- 核心追求稳定跟上市场，卫星追求超额收益
- 核心和卫星之间相关性尽可能低
- 定期再平衡（季度或半年度）

### 5.2 五类经典组合

| 组合类型 | 构成 | 适合人群 |
|---------|------|---------|
| 稳健组合 | 股票型 + 债券型 + 货币型 | 保守型 |
| 平衡风险组合 | 大盘指数 + 单只基金 | 均衡型 |
| 稳中求进组合 | 指数型 + 灵活配置型 | 成长型 |
| 二八轮动组合 | 大盘指数 + 中小盘指数 | 趋势型 |
| 不亏钱组合 | 固收+为主 | 极度保守 |

### 5.3 资产配置经典模型

| 模型 | 核心逻辑 |
|------|---------|
| **美林时钟** | 根据经济周期（复苏→过热→滞胀→衰退）轮动资产 |
| **全天候策略** | 桥水达利欧：任何经济环境下都保持平衡 |
| **风险平价** | 让每种资产的风险贡献相等 |
| **Black-Litterman** | 市场均衡收益 + 投资者主观观点 |

## 六、基金经理分析

### 6.1 中国四大顶流

#### 张坤（易方达）— 巴菲特式价值投资

- **选股核心**：ROE 常年 > 20%，自由现金流充沛
- **"灵魂三问"**：①相信公司的底层逻辑吗？②对长期逻辑有信心吗？③如果三年不能交易还敢买吗？
- **最大教训**："大家觉得增长就是好的，这是最大的谬误" — ROIC < WACC 的增长是毁价值的
- **逆向基因**：2013 年茅台跌 30% 时继续加仓

#### 朱少醒（富国）— 自下而上 + 均衡配置

- **放弃择时**："机构择时对业绩的贡献往往是负值"
- **不押注单一行业**：最看好茅台时也不会极端仓位
- **区分优质公司和明星公司**："耳熟能详的明星公司不等同于优质公司"
- **重视估值匹配**：2020 年后强调"估值考量变得更加重要"

#### 谢治宇（兴证全球）— 性价比为核心

- **卖出铁律**："我彻底看错了，多少钱都卖"；看不懂的波动"随它去吧"
- **均衡配置**：40 只股票，单行业最多 20%
- **不求常胜求长胜**："希望长期优秀业绩，不是短期优秀业绩"

#### 葛兰（中欧）— 创新药赛道专注

- **聚焦创新药产业链**：创新药 + 创新器械 + 创新产业链 + 医疗服务
- **老龄化长期逻辑**：未来十年中国老龄化加速，医药需求大幅增长
- **严格按框架选股**：不被板块内部热点轮动带偏

### 6.2 四大顶流的共性

1. **全部自下而上选股**，不靠宏观判断
2. **全部不依赖择时**，承认短期预测不可能
3. **全部长期持有**，赚企业成长的钱
4. **全部深度研究基本面**：商业模式、竞争力、管理层
5. **能力圈内敢重仓，但组合保持均衡**

### 6.3 全球大师

| 大师 | 核心哲学 | 标志性方法论 |
|------|---------|------------|
| **彼得·林奇** | 投资你熟悉的领域 | PEG 估值、六类公司分类法 |
| **约翰·博格** | 闭眼买指数，越低费越好 | 指数基金，买下整个市场 |
| **瑞·达利欧** | 原则决定长期结果 | 全天候策略、经济机器模型 |
| **霍华德·马克斯** | 周期思维、第二层次思考 | "投资最重要的事"、风险控制优先 |

## 七、各类基金投资要点

### 7.1 债券基金/固收+

**低利率时代应对策略（2025）**：
- 纯债收益率中枢下移（前 5 月平均仅 1.76%）
- 增加跨境复合产品（点心债套利）
- 增加波段操作（信用债、利率债）
- 精细化的回撤控制和止损

**分域适配**：筛选因子因风险类别而异
- 低风险产品 → 侧重信息比率、下行风险
- 中高风险产品 → 侧重 Alpha、选股能力
- 灵活型产品 → 侧重资产配置和择时能力

### 7.2 可转债基金

- 2025 年可转债策略前 5 月平均收益 **5.48%**，远超纯债的 1.76%
- 核心关注：市价、溢价率、YTM、股债平衡属性
- 低波产品转债权重小，高波产品转债权重大

### 7.3 QDII 基金

- 配置价值显著上升（低利率 + 人民币波动）
- 获取跨境利差（点心债、中资美元债）
- 建议配置 0-10%
- 关注：汇率风险、海外投研能力、费率

### 7.4 商品基金

- 主要作为**对冲工具**而非收益来源
- 黄金 ETF 与债券可形成负相关性，降低组合波动
- 关注通胀、利率等宏观因子的变化

## 八、最核心的选基洞察

### 8.1 公募基金整体画像（实证发现）

1. **选股能力是区分好坏的唯一因素**。择时能力在统计上对绝大多数基金不存在。
2. **机构择时对业绩贡献是负值**（朱少醒的结论被实证支持）。
3. **基金规模是负向预测因子** — 规模越大，未来收益越低。
4. **拥挤度是负向预测因子** — 太多人挤在同一赛道时，超额已经消失。
5. **中等回溯期效果最好** — 半年到两年，不是越长越好。

### 8.2 对 ai-invest 的启示

1. **基金分析框架可以系统化** — 500+ 指标可以量化为选基模型
2. **业绩归因是核心能力** — 区分选股收益 vs 行业配置收益，区分 Alpha vs Beta
3. **ETF 策略可集成到 portfolio-review** — 网格参数计算、定投止盈提醒、核心-卫星比例建议
4. **基金经理风格标签** — 为关注的基金经理建立标签体系，跟踪风格漂移
5. **拥挤度监测** — 当某类基金/赛道被过度拥挤时发出警示
