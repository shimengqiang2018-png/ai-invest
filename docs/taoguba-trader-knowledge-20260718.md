## 二、炒股养家：情绪周期心法（公认最高心法）

### 核心六条

1. **所有操作基于情绪揣摩**，进而判断风险与收益比较，指导实际操作
2. **高手买入龙头，超级高手卖出龙头**
3. **别人贪婪时我更贪婪，别人恐慌时我更恐慌** — 顺势而为
4. **敢于大盘低位空仓，敢于大盘高位满仓** — 心中无顶底，操作自随心
5. **永不止损，永不止盈** — 买入机会，卖出不确定
6. **得散户心者得天下** — 人气所向，牛股所在

### 交易的本质是群体博弈

随时衡量**场外潜在买入者的资金量和买入倾向**，与**场内筹码的数量和卖出倾向**的对比：
- 买入倾向 > 卖出倾向 → 买入
- 卖出倾向 > 买入倾向 → 卖出

### 两大情绪驱动力

- **赚钱效应**：短线选手阶段赚钱 → 自信增强 → 持续投入 → 形成群体效应 → 资金不断进场
- **亏钱效应**：追涨失手 → 资金回落 → 反思减少操作 → 群体效应 → 强势股无后继

### 仓位与赢面对应关系

| 赢面 | 仓位 | 说明 |
|------|------|------|
| < 60% | 观望 | "赢面"包括胜率和涨跌空间比两个维度 |
| 60%-70% | 小仓 |
| 70%-80% | 中仓 |
| 80%-90% | 大仓 |
| > 90% | 满仓 | 上涨空间 > 30-50%，下跌空间 < 3-5% |

### 买入时机

- **买在分歧，卖在一致** — 龙头炸板回封是买点，缩量加速是卖点
- 赚钱效应阶段：做热点，直接买强势标的
- 恐慌效应阶段：做超跌，低吸回调
- 超跌最佳时机：大盘/板块连续下跌后集体大幅杀跌，两者共振

### 卖出时机

- **核心原则**：卖出风险，而非卖出盈利
- **判断心法**：忘记成本。假设空仓，还会买吗？会就拿着、会买别的就换、空仓就卖
- 最忌讳：自己都不看好了，因为套了几个点还在犹豫

### 心态口诀

- 买入机会，卖出风险，只做对的交易，胜负交给概率
- 掌握市场之心，胜利接踵而至；心被市场掌握，失败连绵不绝
- 大赚之后要空仓，连亏三日莫开仓

## 三、退学炒股："我和小明"与心理控制

### 核心哲学

**"小明"是谁？** 小明不是别人，是交易者内心那个**懒惰、急躁、好胜、恐惧、侥幸、贪婪的另一个自己**。

> "人与人之间智商的差异很小，性格的差异很大，战胜不了自己，也成就不了自己。"

### 小明的典型表现

- 看到别人赚钱就想追 — **踏空焦虑**
- 连续赚钱后信心爆棚 — 把小概率当大概率
- 大亏后急于扳本 — 赌性复发
- 割肉后股价上涨 — 不愿承认错误
- 空仓时心慌 — 害怕错过机会

### 三种最危险情境

1. **看到别人都赚钱时** — 踏空心理作祟
2. **连续成功后** — 自信心爆棚，盲目出手
3. **大亏之后** — 一心扳本，丧失理智

### 空仓的重新定义

> "空仓不是靠回避股市，也不是靠限制交易来达成，真正意义上的空仓是处在看着盘打开交易软件随时准备下单的状态中完成。"

### 动态回撤线仓位管理

- 资金从最高点回撤 < 10% → 满仓单票
- 资金从最高点回撤 ≥ 10% → 强制分仓（最多2票）

### 核心操作原则

- **错了就割，不抱任何幻想**。操作只有对错，盈利交给市场
- **确定性至上**，不拘泥于模式：打板、低吸、半路、接力只是工具，核心是确定性
- **剥离情绪**：忘掉每一次交易的盈亏，不让上次情绪影响下次判断

### 小周期四阶段模型

| 阶段 | 特征 | 策略 |
|------|------|------|
| 初始期 | 龙头首板/二板，板块联动初现 | 试错首板、最强换手二板 |
| 一致期 | 龙头加速一字，跟风普涨 | 持仓不动，不开新仓 |
| 分歧期 | 中位股掉队，龙头爆量 | 高位核心错杀回封、高低切换 |
| 修复期 | 反包股出现，超跌轮动 | 反包、超跌人气首板 |

### 终极洞见

> "了解别人会让你知道如何赚钱，了解自己会让你知道如何不输钱。"
> "人生的高度取决于格局的大小，小成可以靠运气或小聪明，大成必须依赖一个人的格局。"
> "当你还在为错失机会而痛苦不已时，说明你内心还没有做到无我的境界。"

## 四、92科比：情绪周期四阶段 + 八字真经

### 八字真经

**龙头 — 补涨 — 切换 — 空仓**

### 情绪周期四阶段操作框架

| 阶段 | 特征 | 操作 |
|------|------|------|
| **低位试错期** | 龙头见顶杀高位、新题材萌芽 | 做首板、1进2，轻仓试错 |
| **主升期** | 龙头打出高度，赚钱效应扩散 | 做人气核心（龙头），分歧时介入 |
| **高位震荡期** | 龙头断板但有反包/二波预期 | 做低位补涨 |
| **主跌期** | 龙头及人气股大跌，亏钱效应严重 | **空仓** |

### 补涨与切换的区分

| 维度 | 补涨 | 切换 |
|------|------|------|
| **周期位置** | 主升+高位震荡 | 主跌后的试错期 |
| **形态** | 原有逻辑的发散延续 | 与之前完全不同，新旧对立 |
| **高度** | 低位启动，爆发力强 | 可能已有30-50%涨幅 |
| **成功率** | 较高 | 需不断尝试，控制仓位 |

### 核心语录

- "该弱不弱就是强，该强不强就是弱。"（超预期买，低于预期卖）
- "分歧产生溢价，一致产生风险。"
- "退潮期空仓，就是赚钱。"（不亏=赚）
- "冰点之后是转折，高潮之后是退潮。"
- "小资金也要分仓，不加杠杆，做股票是长期活动。"

## 七、北京炒家：首板之王

### 交易模式

最为固定的模式：**专注低位首板**，6年从未改变。

### 打板分类

| 类型 | 定位 | 要点 |
|------|------|------|
| **秒拉板** | 进攻型 | 必须有板块效应，建议排板而非直接冲 |
| **回封板** | 防御型 | 想卖的都卖了，空头力量削弱，风险较小 |
| **尾盘板** | 投机型 | 尽量少打，容易最高点接盘 |
| **换手板** | 相对稳 | 高位横盘后上板，下午打板优先 |

### 操作特点

- 严格分仓，从不全仓赌一只
- 杀伐果断，止损坚决
- 模式固定，不因行情好坏切换手法

## 九、情绪周期：所有高手体系的共同基石

### 周期循环

```
冰点 → 试错 → 主升（龙头）→ 高潮 → 分歧/震荡（补涨）→ 退潮 → 冰点
  └──────────────────── 循环往复 ────────────────────────┘
```

### 四阶段操作对位

| 阶段 | 所有高手的共识 |
|------|--------------|
| **试错期** | 小仓试错首板/1进2，做潜在龙头 |
| **主升期** | 重仓龙头，克服高位恐惧，分歧时介入 |
| **震荡期** | 做低位补涨，降低仓位 |
| **退潮期** | 空仓。不亏=赚。禁止高位板 |

### 冰点判断

- **小冰点**：连板高度压缩至 2 板，2 板个数 ≥ 3 家 → 小周期开启
- **大冰点**：2 板个数 ≤ 2 或消灭 2 板 → 大周期开启

## 十、12位高手的十大共性原则

### 1. 情绪周期是所有操作的基石
不是 K 线、不是均线、不是 MACD。是对市场参与者心理的理解和预判。

### 2. 只做强势股，只做龙头
"跟风票不看、不做、不研究"（赵老哥）。龙头的确定性最高。

### 3. 买在分歧，卖在一致
分歧 = 上车点（炸板回封、分歧换手板）。一致 = 下车点（缩量加速、一字板）。

### 4. 错了就割，绝不幻想
"错误的交易，第二天集合竞价割，效果最好"（赵老哥+涅盘重升）。

### 5. 空仓是主动选择，不是被迫等待
退潮期空仓 = 赚钱。空仓是交易者最大的自由。

### 6. 杀伐果断，止损坚决
这是 99.99% 股民不具备的素质，也是游资和散户的核心分水岭。

### 7. 分仓管理，永不全仓梭哈
几乎所有高手都分仓。仓位管理是风控的核心手段。

### 8. 模式固定，做减法
"做加法容易，做减法难"（赵老哥）。北京炒家 6 年只做首板。

### 9. 亏钱效应扩散前离场，赚钱效应扩散时重仓
在巨亏效应未大面积扩散前、在赚钱效应未转弱前果断操作。

### 10. 交易系统 + 绝对信任
建立自己的体系后，不对市场抱幻想，只对系统百分之百信任，简单模式反复做。

## 十一、A股短线交易的七种经典战法

| 战法 | 触发条件 | 执行要点 |
|------|---------|---------|
| **弱转强** | 前日超级大烂板，次日异常强势封板 | 5 分钟内结束战斗 |
| **午后首次唯一空间票** | 午后涨停后成为市场唯一最高空间板 | 确定性极高 |
| **尾盘错杀** | 核心龙头尾盘被指数/恐慌带开 | 市场送钱的机会 |
| **龙头第一次加速** | 不断分歧换手后第一次竞价放量大高开加速 | 必买点 |
| **龙回头** | 核心龙头下跌 20-30% 后止跌企稳 | 二波机会 |
| **三板断板后反包** | 三板后断板，次日开盘 5 分钟内强势反包 | 强转更强 |
| **龙虎榜机构大买** | 3 家以上机构上榜买入的首板，次日低吸 | 机构背书 |

## 十二、对投资的深层启示

### 对价值投资的启示

淘股吧高手的体系看起来是**纯短线博弈**，但底层逻辑与价值投资有深刻相通之处：

1. **安全边际** = 分歧买点 — 价值投资的"股价低于内在价值时买入"与短线"分歧时买入"，本质都是在寻找**市场定价错误**的时刻。分歧 = 多头和空头打架，价格被压到非理性低位 → 内在价值 > 市场价格。

2. **能力圈** = 模式固定 — 北京炒家 6 年只做首板、赵老哥只做龙头不打跟风。这和巴菲特的"只在你理解的领域投资"是同一个道理。**知道自己不做什么，比知道自己做什么更重要。**

3. **Mr. Market** = 情绪周期 — 格雷厄姆的"市场先生"每天给报价，短线高手把这种情绪波动**量化到了情绪周期的四个阶段**。两者都在利用市场情绪，而非被市场情绪利用。

4. **耐心等待** = 空仓 — 退学炒股说"空仓是最高级的技能"，查理芒格说"我们大多数时候什么都不做"。表述不同，本质相同。

5. **挥棒纪律** = 只做龙头 — 泰德·威廉姆斯的"只挥棒甜蜜区的球"和李录强调的"一辈子只有20个投资机会"，与游资"只做辨识度最高的那一只"是同一逻辑。

### 对 ai-invest 的启示

1. **情绪周期可以量化** — 涨停家数、连板高度、赚钱效应扩散程度，这些都是可量化的指标。ai-invest 可以在投资报告中增加 A 股市场情绪温度计。

2. **分歧/一致框架可用于判断买卖时机** — "买在分歧，卖在一致"可以翻译为价值投资的语言：在负面新闻最多、市场最恐慌时深入研究，在所有人一致看好时重新审视持仓。

3. **交易系统 > 单次判断** — 退学炒股"操作只有对错，盈利交给市场"和量化投资的"不要盯住单次交易结果"完全一致。构建系统，信任系统。

4. **知行合一是最难的一环** — 跨周期的纪律性、不因盈亏改变下一次判断、剥离情绪客观应对 — 这不仅是交易者的修炼，也是投资者的修炼。
